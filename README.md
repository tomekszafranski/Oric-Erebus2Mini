# Mini EREBUS II for Oric-1/Atmos

## Description

Oric-1 and Oric Atmos were 8-bit machines designed in early 80's by Tangerine Computer Systems to compete with Sinclair ZX Spectrum. The success was however very limited at best. Both machines differed only in keyboard and had 6502 processor, 16KB ROM, 48KB RAM and used tape as storage however, they were also equipped with ports for printer and extensions.

Extension port allows today to build simple solution to read programs from SD card. The solution is called EREBUS and consist of couple of gates and flip-flops and 64KB of ROM. This project is mini version based on its mix called EREBUS II that uses GAL insted of mentioned logic gates:

* The PCB is much smaller then original EREBUS (and EREBUS II as well)
* PCB is directly (without IDC cable) connected to Oric extension port
* Additionaly, this is Reset switch :-) because not-easily-accessible switch on botton is NMI.
