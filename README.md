# Mini EREBUS II for Oric-1/Atmos

## Description

Oric-1 and Oric Atmos were 8-bit machines designed in early 80's by Tangerine Computer Systems to compete with Sinclair ZX Spectrum. The success was however very limited at best. These machines used tape as storage however were also equipped with IDC connector that allow to read programs from SD card. Solution is called EREBUS () and this is mini version of (). I've decided to beuild as small as possible PCB that is connected directly (without the cable) to rear connector.
