# Mini EREBUS II for Oric-1/Atmos

## Description

Oric-1 and Oric Atmos were 8-bit machines designed by Tangerine Computers in early 80's to compete with Sinclair ZX Spectrum. The success was however very limited at best. These machines used tapes as storage device however were equipped with IDC connector that allow to read programs from SD card. Solution is called EREBUS () and this is mini version of (). I've decided to beuild as small as possible PCB that is connected directly (without the cable) to rear connector.
